## Decided
Summaries of books 1 to 3 of Dungeon Crawler Carl are kept as reference markdown for anyone designing characters, levels and jokes. Start with the README for the index, then the characters, levels-and-looks and world-and-system files; the three per-book files hold full spoiler summaries with timelines, floor looks, enemy catalogs and game ideas. Everything is paraphrased, so check the books for exact wording.

## Tried and ruled out
Searching the book notes with trail ask: it indexes code only, so these markdown files are not found that way. Use grep or open the files.

## Watch out
Key looks from the books: Mordecai starts as a bearded rat in a black vest, blue pants and sandals, then changes form each floor (bear-like Bugaboo, gray Incubus in a tuxedo, mud-colored toad). Donut is a tortoiseshell Persian with yellow eyes, a purple jeweled tiara and a jingling butterfly charm. Carl is barefoot with heart-print boxers, a one-sleeved leather jacket and no pants. Goblins carry pineapple-on-a-stick clubs. Floor 1 is a dark red-brick grid lit by green lichen; Floor 2 flips to white floors and orange lichen; Floor 3 is a fake-sky medieval city under a red sun; Floor 4 is a Soviet-style subway network.
