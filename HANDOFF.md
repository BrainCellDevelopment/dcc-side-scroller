# Handoff: DCC Side Scroll, Level 0

Fan game based on Dungeon Crawler Carl, built with Lukas. Godot 4.7.2, typed GDScript, Compatibility renderer. Godot project is the inner `dcc-side-scroller/` folder (contains `project.godot`). Branch: `feature/level-0` (from `develop`). Nothing committed or pushed yet.

## Rules from the owner
- Keep code comments to an absolute minimum.
- Make no mistakes; verify before saying something works.
- Carl fights with fists only (no club).
- Game must adapt to any screen size (640x360 base, stretch `canvas_items`, aspect `expand`).
- Graft is added to the project (project-only) and should always be used. `graft/` is git-ignored.

## Current request (unfinished)
Level 0 must take 5 to 8 minutes for a first-time player (it was about 30 seconds), and the art must look like Mega Man / Metal Slug style pixel art instead of blocky ColorRects.

Done: new level (about 25k px, 7 sections), new pixel art for all characters, terrain, backgrounds, props, boss and FX, generated by Python/PIL scripts in `art-src/`.

## Key code
- `scripts/autoload/game.gd`: checkpoints, input actions registered at runtime, shake, boss/loot signals.
- `scripts/levels/level00.gd`: phases PLAY/ARENA/HANDOFF/CHASE/AFTERMATH/COMPLETE, public `section` and `complete`.
- `scripts/enemies/dozer.gd`: vulnerability cycle; stomp only while `vulnerable`.
- `scripts/util/sprite_util.gd`: builds AnimatedSprite2D from sheets (origin bottom-centre).
- Collision layers: world 1, player 2, enemy 4. Groups: player, enemies, hazards, kill_zones, checkpoints, platforms. Damage: `take_damage(amount, from)`.
- `contract-art.md` has the sprite sheet specs; `contract-gameplay.md` has the original interfaces (both in `docs/`).

## Gotchas
- Python generators in `art-src/` hardcode paths now repointed to this repo; generators need Pillow (use a venv, e.g. /tmp/artvenv/bin/python); `build_level00.py` writes `scenes/level00.tscn` and must keep `uid://dsypb287qo2hi` (it does) or the main scene fails to load.
- `build_level00.py` has a built-in linter (reachability: gaps up to 64 px, step-up up to 48 px). Keep it at 0 errors.
- The level scene is generated: edit the generator, not the .tscn.
- macOS has no `timeout`; use `--quit-after`.
